ROS2 Hero — ห้องฝึก ROS 2 Jazzy

บทเรียนอยู่ที่  https://ros2hero.allmobilerobotics.com
เรียนตามลำดับ:  ROS คืออะไร  →  STEP 0 (หัวข้อ 3 เป็นต้นไป)  →  STEP 1  →  STEP 1 (ต่อ) เขียนโหนดเองด้วย Python

พิมพ์คำสั่งที่ไหนก็ได้ — ผลเหมือนกัน
  เทอร์มินัลของ VS Code (แท็บแรก) ก๊อปคำสั่งจากหน้าเว็บมาวางได้เลย  ← แนะนำ
  หรือ Terminator บนเดสก์ท็อปนี้
หน้าต่างอย่างเต่าจำลองจะขึ้นที่เดสก์ท็อปนี้เสมอ

ลองว่าพร้อมใช้
  ros2 run demo_nodes_cpp talker
  (กด Ctrl+C เพื่อหยุด)

ไฟล์ที่สร้างในเครื่องนี้อยู่จนกว่าจะลบ codespace ที่ github.com/codespaces
